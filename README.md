# Proyecto Primer Bimestre Servidor HTTP/1.1 
### Erick Cuichan
---
Servidor con implementación de el protocolo HTTP/1.1 para atender solicitudes GET, manejar descriptor de archivos y gestionar múltiples conexiones utilizando sockets no bloqueantes y el mecanismo de multiplexación de eventos epoll.
---

## Compilación y ejecución
- Para compilar:
make
- Para ejecutar 
make run
- Acceder desde el browser
http://127.0.0.1:8080/ (index.html - style.css - image.png)
